# cupidPkg

The Xiaomi 12's platform package for Mu-Silicium, carried by HakiOS's UEFI. Modelled on `negroniPkg` (the OnePlus
10 Pro, the same `WaipioPkg` SoC package) and on `redwoodPkg` (HakiOS's own boot path: the XNU loader is started by
the Boot Manager, not by a platform application).

**Scaffold: not built, not run.** See `uefi/README.md` here for what is real and what is not.
